# CorvexPanel

CorvexPanel is a modern hosting control panel based on the myVesta engine.

The goal of CorvexPanel is to provide a lightweight and reliable hosting control panel with a modern UI and integration with the Corvex365 ecosystem.

## Features

- Web hosting management
- Domain management
- DNS management
- Mail server management
- Database management
- FTP management
- SSL (Let's Encrypt)
- Multi-user hosting environment

## Project Status

This project started as a rebranded fork of myVesta.

Future plans include:

- modern UI redesign
- Corvex365 Billing integration
- API layer
- module system
- improved security

## Architecture

CorvexPanel uses the proven Vesta/myVesta provisioning engine.

Main components:

- `bin/` provisioning scripts
- `func/` helper functions
- `src/` configuration templates
- `web/` control panel interface
- `install/` installer
